## English

- Notification forwarding now includes Big Picture and MessagingStyle images, including image-only notifications, as Base64 in the JSON images array using chunked HTTP uploads.
- Sources → Graphics adds JPEG/PNG selection, JPEG quality, configurable attachment count, dimension and size limits, and separate avatar and app-icon switches that are off by default.
- Connection → Test message lets you independently include a big picture, two-image gallery, avatar and app icon without changing notification capture settings.
- The optional automatic app-selection setting selects newly discovered launcher apps when you open or return to Message487 while preserving existing choices and manual exclusions.
- Duplicate notification filtering now accounts for image content, roles and presentation regardless of image order, so matching text with different images is not treated as a duplicate.
- Notification text still proceeds when image processing fails, runs out of memory, times out or overflows its queue, and SMS capture no longer waits behind notification processing.
- Settings loading, storage operations and system queries now run off the UI thread, with a Retry button when initial settings loading fails.
- Webhook delivery, update checks and downloads now disconnect when cancelled and enforce a two-minute total request deadline, including when a server keeps sending data slowly.
- Added five importable n8n examples for text/image webhooks and Telegram forwarding, including an advanced Rich Message workflow that requires a custom node and saves successful-part progress for retries.
- Replaced launcher artwork, themed icons and notification icons with new monitor-and-phone designs, with extra spacing for circular launcher masks.

## Русский

- Добавлена пересылка изображений Big Picture и MessagingStyle, включая уведомления без текста, в массиве images JSON-запроса с кодированием Base64 и передачей HTTP по частям.
- В разделе «Источники → Графика» появились выбор JPEG/PNG, качество JPEG, лимиты количества вложений, размеров и объёма, а также отдельные переключатели аватаров и значков приложений, выключенные по умолчанию.
- В разделе «Тестовое сообщение» настроек подключения можно независимо выбрать большую картинку, галерею из двух изображений, аватар и значок приложения, не меняя настройки сбора уведомлений.
- Необязательный автоматический выбор добавляет новые обнаруженные приложения со значком запуска при открытии или возврате в Message487, сохраняя текущий выбор и ручные исключения.
- Фильтр дублей уведомлений теперь учитывает содержимое, роли и способ представления изображений независимо от их порядка, поэтому одинаковый текст с разными картинками не считается дублем.
- Текст уведомления продолжает обрабатываться при ошибке изображения, нехватке памяти, тайм-ауте или переполнении очереди изображений, а сбор SMS больше не ждёт обработки уведомлений.
- Загрузка настроек, операции с хранилищем и системные запросы перенесены с потока интерфейса, а при ошибке начальной загрузки настроек появляется кнопка повтора.
- Доставка на webhook, проверка и загрузка обновлений теперь закрывают соединение при отмене и ограничивают общую длительность запроса двумя минутами, в том числе при медленной непрерывной передаче данных сервером.
- Добавлены пять импортируемых примеров n8n для текстовых и графических webhook и пересылки в Telegram, включая расширенный сценарий Rich Message с дополнительным узлом и сохранением прогресса успешно отправленных частей для повторов.
- Заменены значки запуска, тематические значки и значки уведомлений на новый рисунок монитора и телефона с дополнительными отступами для круглой маски запуска.
