## English

- Added delivery troubleshooting on Overview with checks for saved connection settings, sources, permissions, listener connectivity, network, background restrictions and queued failures, plus links to corrective actions.
- Added previews of test events and up to 20 active notifications from selected apps, showing JSON metadata, available images and the destination, with an explicit send action; opening a preview sends nothing and leaves automatic capture running independently.
- Manually sent test events and their automatic retries can now be delivered while forwarding is paused, without resuming ordinary capture or queued message delivery.
- Added export of saved connection, source, duplicate-filter and image settings to unencrypted JSON, including the Bearer token by default with a switch to exclude it.
- Added settings import with validation and confirmation before replacement; forwarding is paused afterward, a missing token clears the current token, and existing queued events retain their destinations and credentials.
- New webhook events include channel_id with the Android notification channel ID when available, sms for SMS or test for tests, while existing queued bodies remain unchanged.
- Updated launcher icons to white monitor-and-phone artwork on a dark purple background.
- The footer now places the GitHub link inline alongside the app version and commit hash.

## Русский

- На экране «Обзор» добавлена диагностика пересылки с проверками сохранённого подключения, источников, разрешений, службы уведомлений, сети, фоновых ограничений и ошибок очереди, а также переходами к действиям для их устранения.
- Добавлен предпросмотр тестовых событий и до 20 текущих уведомлений выбранных приложений с метаданными JSON, доступными изображениями, адресом получателя и отдельной кнопкой отправки; открытие предпросмотра ничего не отправляет и не останавливает автоматический сбор.
- Вручную отправленные тестовые события и их автоматические повторные попытки теперь доставляются во время паузы без возобновления обычного сбора и доставки сообщений из очереди.
- Добавлен экспорт сохранённых настроек подключения, источников, фильтров дублей и изображений в незашифрованный JSON, включающий Bearer-токен по умолчанию с возможностью его исключить.
- Добавлен импорт настроек с проверкой и подтверждением перед заменой; после импорта пересылка приостанавливается, отсутствие токена в файле очищает текущий токен, а события в очереди сохраняют прежние адреса и учётные данные.
- Новые события веб-хука содержат channel_id с ID канала уведомления Android, если он доступен, значением sms для SMS или test для тестов, а тела событий в существующей очереди не меняются.
- Значки запуска обновлены: белые монитор и телефон на тёмно-фиолетовом фоне.
- Ссылка GitHub теперь встроена в текст нижней части экрана рядом с версией приложения и хешем коммита.
