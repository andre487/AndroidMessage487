## Находка и retest

**F01 — read-only dry-run блокируется HTTP 404.** В кандидате api("") строил
repos/andre487/AndroidMessage487/; живой GitHub возвращает 404. Endpoint без slash
возвращает metadata с allow_squash_merge=true.

В отдельной новой ветке fix/release-dry-run-repository-url исправлен только
repository endpoint. Новый regression test фиксирует правильный read-only GET;
полный Python lane и вызов исправленного helper на живом GitHub PASS.
Это не полный workflow с RELEASE_BOT_TOKEN/OpenAI: нужна публикация исправления
и повтор R01. Исходный FAIL остаётся до live retest.

Расхождения fixture не приняты за app bugs: Android 15 при прямой правке preferences
мог продолжать читать уже загруженное состояние listener. Controlled capture presets
повторены с реальным NotificationManager revoke/grant; migration API 35 повторена
через UI. Снимки SQLite учитывают WAL. Отсутствие записи только в main DB-файле не
считалось потерей очереди. Незавершённые попытки UI automation не заменяют конечные PASS.

## Доказательства и восстановление

Сырые материалы локальны: dist/release-test-2026-10-05/evidence — UTC
runtime-results.jsonl, requests.jsonl, build/CI logs, environment/APK identity,
screenshots/XML, SQLite/WAL, diagnostic ZIP, migration и negative probes.
Каталог закрыт (0700), чувствительные файлы 0600. Токены, TLS private keys, базы,
ZIP и raw logs не включаются в Git. Probe APK/source остаются в игнорируемом dist.

Сеть, font/rotation/theme/battery восстанавливались после проб.
На каждом эмуляторе foreground/background soak длился 945 секунд (15 минут 45 секунд):
9/9 уникальных synthetic notification были приняты с matching ACK. Пробы чередовали
Home и возвращение в приложение, не использовали force-job для доказательства естественного
расписания. Это эмуляторное доказательство, не OEM/суточный тест.

Refs, PRs и releases до/после dry-run совпали. Внешняя публикация не выполнялась.
Очистка завершена: pending queue 0 на обоих AVD перед остановкой; сеть,
battery/Doze, font/theme/rotation восстановлены. Probe удалён, оба созданных AVD
остановлены и удалены вместе с synthetic app data/Keystore/test CA. Три собственных
loopback HTTPS сервера остановлены, приватные TLS keys и временный Bearer token
удалены. ADB forwards/reverses не создавались. ADB после очистки пуст.

Из существующего локального n8n через штатный REST API удалены только 14 executions
двух smoke-прогонов: отбор по двум временным окнам и synthetic marker либо явно
пустому Webhook body validation-пробы. Другие workflows/credentials/volumes не
менялись, n8n оставлен работать. Существующие AVD и остальные Docker контейнеры
сохранены. Остались signed APK/baseline и закрытые обезличенные raw evidence в dist;
Исправление и этот отчёт подготовлены в отдельной ветке fix/release-dry-run-repository-url.
