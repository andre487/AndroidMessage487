For beginners, we recommend **n8n Cloud**: n8n maintains the server and you configure
it through the website. Cloud offers a trial and paid plans; see the current terms
on the [n8n website](https://n8n.io/pricing/).

Both setups let the app send messages to an authenticated endpoint and receive
confirmation. After a successful test, you can add [Telegram forwarding](n8n-telegram.md).

If you haven't installed the app, start with [APK installation](apk-installation.md).
More help: [official n8n documentation](https://docs.n8n.io/) and
[Cloud versus self-hosting](https://docs.n8n.io/choose-how-to-use-n8n).
